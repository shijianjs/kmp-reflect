<ktjs-features section-title="它能做什么" tinted>

<ktjs-feature icon="lucide:boxes" title="元数据就是普通 Kotlin">处理器把 `KmpClass`、`KmpFunction`、`KmpProperty` 等写成源码，所有后端都能编译——没有运行时反射，也不加载类。</ktjs-feature>

<ktjs-feature icon="lucide:tag" title="按类显式开启">只有标了 `@KmpReflect` 或实现 `KmpReflectable` 的类才会被记录，扫描也只在这批类里进行。</ktjs-feature>

<ktjs-feature icon="lucide:terminal" title="像反射一样调用">`KmpClasses.of<Person>().function("greet")?.invoke(person, "Hello")`，`suspend` 函数走 `invokeSuspend`。</ktjs-feature>

<ktjs-feature icon="lucide:copy" title="编译期生成代理">`@KmpReflect` 接口会得到代理类，把所有调用转发给 `KmpInvocationHandler`，不依赖 `java.lang.reflect.Proxy`。</ktjs-feature>

<ktjs-feature icon="lucide:file-archive" title="资源不需要运行时">配置的目录在编译期被读取并以内联 Base64 写入源码，附带 MIME 类型与大小，浏览器和 native 读法一致。</ktjs-feature>

<ktjs-feature icon="lucide:layers" title="覆盖每个 KSP 目标">JVM、JS、Wasm 与 Kotlin/Native 拿到同一份生成代码；Gradle 插件按目标注册处理器。</ktjs-feature>

</ktjs-features>
