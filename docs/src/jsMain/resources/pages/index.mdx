# kmp-reflect

Reflection for Kotlin Multiplatform, generated at compile time by KSP — class metadata, annotation
data, invocation, dynamic proxies and inlined classpath resources, all as ordinary Kotlin source.

```kotlin
KmpReflection.register(DemoReflection)

val personClass = KmpClasses.of<Person>()
val instance = personClass.constructor(3)?.new("Ada", 36, "hidden")
personClass.function("greet", 1)?.invoke(instance, "Hello")   // "Hello, Ada!"
```
